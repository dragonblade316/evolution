# Bno085

BNO08x IMU source using Raspberry Pi SPI0 CE0. The default wiring is:

- CE0: BCM GPIO8
- MISO: BCM GPIO9
- MOSI: BCM GPIO10
- SCLK: BCM GPIO11
- RSTN: BCM GPIO24
- HINTN: BCM GPIO25

The source opens `/dev/spidev0.0` and `/dev/gpiochip0`, initializes the sensor, and enables
the calibrated gyroscope report. A worker thread owns the non-`Send` BNO08x driver. Each
Copper cycle drains pending sensor messages and publishes the gyroscope Z axis as yaw
angular velocity in radians per second.

The default mission feeds this output and wheel-derived chassis velocity into
`DiffDriveOmegaFusion`. The source is disabled for simulation and the PC mission.

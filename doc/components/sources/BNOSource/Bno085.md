# Bno085

BNO08x IMU source over SPI. Reads gyro angular velocity each cycle via `bno08x-rs`. `preprocess` drains up to 5 sensor messages; `start` initializes the IMU. Config selects the SPI device and the interrupt/reset GPIO symbols.

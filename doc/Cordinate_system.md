There are two main cordinate systems that the robot will use, the local cordinate system and the global system.

## Local
The local cordinate system is as follows:
origin point: Center of robot
x: To the right of the robot
y: To the front of the robot
theta: Counter Clockwise

## Global
The global cordinate system is as follows
origin point: Bottom left corner of field. 
x: To the right
y: Moving forward
theta: Counter Clockwise. (0 is pointing up)


## Game spesific
The point which is considered the bottom left will need to be defined for each game.
- Liftoff: The corner of the bottom left goal
